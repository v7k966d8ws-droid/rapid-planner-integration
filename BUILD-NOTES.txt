Rapid Planner Integration — Build 3.5
27 September 2026

UI-only change:
- Tonight's Program job cards are substantially more compact on iPad/laptop.
- Reduced job-card padding, header spacing, injection table row height, typography and action-button size.
- Water-only jobs remain especially compact because they have no injection table.
- No changes to Rapid Planner calculations, shift logic, save integration, sequencing, history logic or injector calculations.

MULTI-NIGHT VAT TEST — 2026-10-01
- Prepared vats now persist after a Night Program is saved.
- A night may save only part of a prepared vat; remaining outlets/volume carry to the next night.
- Previously fertigated outlets are disabled as Already allocated on following nights.
- Remaining litres include usage committed on earlier nights plus current draft jobs.
- Final vat rinse is added only when the current night contains the last remaining outlet(s).
- Cancelling/starting a Night Program no longer deletes the physical prepared vat.
- Existing double-save replacement logic retained unchanged.

VAT RUNTIME ALLOCATION UPDATE (9 OCT 2026)
- Prepared vat injection minutes apportioned by cumulative hectares across the whole vat, including multi-night outlets.
- AquaLink rounded-minute allocations sum to rounded full-vat runtime; no independent rounding per shift.
- Validate selected injector flow and prepared vat volume before saving.
- Existing Diary View and other integration features retained.
